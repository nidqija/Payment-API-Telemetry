v1.0.0 Idempotency Foundation

Fintech-Grade Idempotency Engine & PostgreSQL Schema

Oct 01 - Oct 02, 2026
🛡️ Concurrency & Integrity Control
  • Strict SHA-256 Request Fingerprinting
    Every payload is hashed via SHA-256. If a client attempts to reuse an existing idempotency key with modified payload parameters, the API immediately rejects the call with 422 Unprocessable Entity.
    SHA-256 Hashing HTTP 422 Tamper Protection
  • Atomic Locking & Duplicate Request Polling
    Utilizes INSERT ... ON CONFLICT DO NOTHING in PostgreSQL. Concurrent requests for the same key poll the record with exponential backoff until completion or return 409 Conflict upon timeout. Completed transactions replay their historical response with zero processing delay.
    PostgreSQL ON CONFLICT Polling Fallback HTTP 409 Conflict
  • Database Migrations & Direct CLI Tooling (psql.ps1)
    Authored docker/init.sql with indices, tables for merchants, api_keys, payments, and idempotency_records. Created a convenient PowerShell script (psql.ps1) for executing arbitrary SQL queries directly into the container.
    docker/init.sql psql.ps1 PostgreSQL 16
